Case 6: LifeVac 
Your client is a large pharmaceutical company, LifeVac Corp., specializing in vaccines.  As part of its strategy to expand into emerging 
markets, the company is considering applying for a vaccine protocol program in Brazil.  The protocols are government managed programs 
designed to vaccinate infants against prevalent childhood diseases.  Companies can only apply for one vaccine protocol. If LifeVac is 
chosen, it would have exclusive rights to provide vaccines to the government for a five-year period.  However, as a prerequisite to applying, 
the Brazilian government requires all applicants to build a manufacturing plant in the country.  You have been hired to assess whether or not 
LifeVac should apply for a vaccination protocol, and if so which vaccine it should apply with. 
This is a candidate-led case that requires the candidate to drive the structure and flow of the case. However, the interviewer should guide the 
candidate if he/she is not addressing the key components described on the following pages, as many candidates’ initial frameworks will not lead 
them to the desired analysis. The core of the case is about evaluating which of LifeVac’s vaccines should be put forward for the protocol. All three 
options are profitable, so the initial question of whether to proceed at all becomes secondary. The first piece of analysis is to understand the 
potential profitability of each vaccine. The second is to factor in the probability that an application for each vaccine would be accepted. The 
third, optional piece is to think about how to influence or learn more about that probability. 
 
A stronger candidate will move towards the expected value analysis without much prompting after learning that the probability of having the 
application accepted varies by vaccine. Although the interviewer will likely need to steer the candidate back on course from time to time, a strong 
candidate will take the interviewer’s cues and proactively seek to regain control and drive the case.

Sample Analysis 
Expected Value Analysis 
• For each vaccine the initial investment is a certain and unrecoverable cost; revenues however are all subject to application approval, 
which has a varying but unknown probability for each vaccine.  
• The candidate must determine what acceptance probability would make each investment expected value positive; the lower the 
acceptance probability required to make the investment viable, the better 
• What % probability creates an expected value of 0? Anything better than this will be ‘viable’ (i.e. ignore cost of capital/required return)  
• Set expected value at zero and solve for % probability. Expected value = (% probability) x (revenue) – (investment cost).  If expected 
value is 0 then (% probability) x (revenue) - (initial investment cost) = 0. This is the same as (% probability) = (investment cost) / (revenue) 
• Solve for (% probability) for each vaccine:  
• Vaccine 1: (% probability) = 45/225 = 20% 
• Vaccine 2: (% probability) = 30/180 = 16.7% 
• Vaccine 3: (% probability) = 25/135 = 18.5% 
 
The fact that each vaccine may have a different probability of being accepted creates the need for expected value analysis. It is not enough to 
know which option is potentially the most profitable; if that application is not successful the company will lose its investment entirely. Give the 
candidate an opportunity to reach this analysis independently, however if necessary guide him/her here. 
Key takeaway:  Vaccine 2 requires the lowest probability of acceptance in order to be viable
